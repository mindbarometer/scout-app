Privacy policy

Last updated: 22 November 2026

scout is a personal, non-commercial tool used only by its owner. This policy describes how it handles data from the single Google account that grants it access.

What data is accessed

scout requests the read-only Gmail scope (gmail.readonly) for one dedicated mailbox that exists only to receive job-alert emails. It reads messages from the last few days in order to extract job titles, company names, short descriptions and links to the vacancies.

How data is used

The extracted vacancy information is used only to build a private list of job openings for the owner's own job search. scout never sends, modifies, deletes or labels emails.

Sharing

Data is not sold, shared with or transferred to third parties, and is not used for advertising or for training machine-learning models. Access tokens are stored only as encrypted secrets of the owner's private repository.

Google API Services User Data Policy

scout's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/mindbarometer/scout-app.
